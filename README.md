# SPIKE Block Lab

ChromebookでLEGO Education SPIKE PRIMEをプログラミングするWebアプリ。**v0.2.0・標準Hub OS向け・実機未検証の試作版**です。

まず、LEGO SPIKEアプリの本体実行に関わる基本機能を、EV3 Block Labと同じユーザーインターフェースで使えるようにすることを優先します。SPIKE-RT用コード生成は将来の発展目標です。実機テストはプロジェクトオーナーが担当します。

## 画面

- EV3 Block LabのCSSと配置を継承
- 上部：プログラム名、新しいプログラム、保存、開く、マイブロック
- 中央：Blocklyのブロック編集、サンプル、元に戻す・やり直す
- 右上：「接続・転送」でパネルを開閉。閉じると編集領域を広く使える
- 下部：生成確認、通信ログ

## 標準Hub OS向けの機能

| グループ | 実装した内容 |
|---|---|
| イベント | 複数スタート、条件成立、メッセージ送受信 |
| モーター | 速度％、度・回転・秒指定、連続回転、ブレーキ・惰性・保持 |
| 走行 | 左右ポート設定、タイヤ直径、距離・時間・角度指定、ステアリング、左右別速度 |
| 表示・ライト | 絵、英数字文字、1ドット表示、本体ランプ |
| 音 | 本体で鳴らす音の高さ・時間・音量 |
| 制御 | 回数・無限・条件付き繰り返し、条件分岐、条件待ち、全終了 |
| センサー | 距離・測定有効判定、色・反射光、フォース・押下、本体左右ボタン、姿勢角度、回転角度、タイマー |
| 演算・データ | 数値・比較・論理・関数・乱数、変数、文字列、リスト |
| マイブロック | 引数付き定義と呼び出し、専用作成フォーム、書き出し・読み込み |
| 保存・実行 | 作品保存・自動保存、Bluetooth転送、転送して実行、停止、センサー通知表示 |

サンプル10種類：表示・ライト、音だけ、モーターA、前進・後退、距離で停止、赤で音、変数と分岐、引数付きマイブロック、並行処理、メッセージ。

## LEGO SPIKEアプリとの対応範囲

公式アプリの完全互換品ではありません。上表は実装済みのコード生成機能であり、実機動作の確認はこれからです。

- 対象はSPIKE App 3対応の標準Hub OS。Bluetooth接続を実装しています。USB転送は未実装です。
- 本体に保存して、切断後に本体で実行する設計です。再起動後の保存保持は実機テスト項目です。
- 本体だけで実行できる命令を優先します。PC側の画像・録音・拡張効果音・クラウド教材は対象外です。
- `.llsp3`の読み込み・書き出し、公式教材・画像・音声素材との互換性はありません。
- EV3 Block Labの`.ev3lab`にも互換性はありません。
- 100％は1050度/秒として換算。対象はSPIKE PRIMEのL/Mアンギュラーモーターです。
- 距離移動はタイヤ直径を基に計算します。走行精度は機体・負荷・取り付けで変わります。
- 本体の文字表示は英数字・記号。日本語文字は転送した本体では表示できません。
- メッセージは同名の受信処理へ通知します。受信処理中の複数通知は次の1回へまとめます。送信完了待ちは未実装です。
- 「やさしいことば」は基本ブロックとグループ名を切り替えます。全ブロックの学年別表現は引き続き調整します。
- マイブロックの引数変更はBlocklyの編集ボタンで行えます。引数のブロックは変数グループを使用します。

## 起動

Node.js 24以上とPython 3（生成コードの構文試験用）を使います。

```sh
npm ci
npm test
npm run build
npm start
```

http://127.0.0.1:8766/ をChromeで開きます。公開用ファイルは`dist/`。配信時はHTTPSと学校端末のBluetooth接続許可が必要です。ビルド後のアプリはBlocklyをローカルに同梱し、CDNに依存しません。

`npm run export:sample`で`generated/standard/`へ10種類の編集可能な作品とPythonを出力します。

## 保存と転送

「保存」は後で編集する`.spikelab`作品です。「SPIKEに転送」は本体への保存です。転送成功はCRC付き要求への本体応答を確認した状態で、EV3版の全バイト読み戻し照合とは異なります。同じ番号を上書きし、途中失敗で旧プログラムが残る保証はありません。

自動保存は同じブラウザの1作品分です。クラウド保存ではありません。ブラウザの停止操作は接続中だけ有効です。本体の停止操作も最初に確認してください。

- `app.js`：画面、作品・マイブロック保存、転送操作
- `classroom-blocks.js`：SPIKE用のブロックとパレット
- `standard.js`：標準Hub OSで動く非同期Python生成

- `spike-ble.js`：SPIKE App 3通信とセンサー通知
- `model.js`, `blocks.js`：保存検証、初期形式との互換
- `generate.js`, `rt-template.cdl`：将来のSPIKE-RT対応に向けた初期検討。現在の画面には表示しません
