# SPIKE Block Lab

Chromebookでブロックをつなぎ、LEGO Education SPIKE PRIMEへ転送して、本体だけで動かすためのWebアプリです。**v0.1.0・実機未検証の試作版**です。実機テストはプロジェクトオーナーが担当します。

通常授業では標準Hub OSを使い、クラブ活動などの発展学習では同じブロックからSPIKE-RT用のCソース一式を生成します。SPIKE-RTのコンパイル時間より、コードの読みやすさと再現できるビルドを優先します。

## 初期版でできること

- Blocklyで順次実行、ライト表示、時間指定モーター、待機、回数・無限繰り返し、距離による条件分岐を編集
- 「やさしいことば」「漢字を使うことば」の切り替え
- 元に戻す・やり直す・全体表示、お手本3種類
- `.spikelab`作品の保存・読み込み、同じブラウザ内の1作品分の自動保存
- SPIKE App 3 Hub OS用Pythonの表示・保存
- Web Bluetoothによる標準Hub OSへの保存、別操作での実行・停止
- SPIKE-RT v0.2.0用のC・ヘッダ・CFG・CDL・ビルド手順をZIP出力
- SPIKE-RT生成コードでの中央ボタンによる開始・停止、ループの待機、使用モーターの終了時停止

## 確認状況と制限

- 自動試験とブラウザ確認の結果は実装時の報告を参照してください。実機での接続・単独実行は未確認です。
- SPIKE-RTの完全なツールチェーンでのビルドと実機動作は未確認です。まずライト表示から確認してください。
- SPIKE-RTはソース出力までです。クラウドビルドの受付、ブラウザDFU書き込みは未実装です。
- スタートは1個です。変数、マイブロック、並行処理、カラー・フォース・ジャイロ、走行距離・旋回、CSVは未実装です。
- EV3 Block Labの`.ev3lab`、LEGO純正の作品ファイルとは互換性がありません。
- モーターの「ゆっくり／ふつう／はやく」は90／180／360度/秒です。パワー％ではありません。
- 転送成功はCRC付き各転送要求への応答を確認した状態です。EV3版の全バイト読み戻し照合とは異なります。
- 転送で同じ番号のプログラムを上書きします。途中失敗で以前のプログラムが残る保証はありません。
- ブラウザの停止は接続中だけ有効です。標準Hub OS側の本体停止操作は実機で確認してください。
- ブラウザを閉じたり、閲覧データを消去すると自動保存を失う場合があります。作品ファイルも保存してください。
- ビルド後の配信にCDNは不要です。オフライン起動用Service Workerは未実装です。

## 手元で動かす

Node.js 24以上を使います。

```sh
npm ci
npm test
npm run build
npm start
```

http://127.0.0.1:8766/ を開きます。外部へ配信する場合はHTTPSが必要です。学校のChrome設定でBluetooth機器の接続を許可する必要がある場合があります。

公開用ファイルは`dist/`です。GitHub Pagesなどへの公開はまだ設定していません。

## 実機テスト

[TESTING.md](TESTING.md)に確認順と記録項目をまとめています。

`npm run export:sample`で`generated/`へPythonとSPIKE-RTプロジェクトを生成できます。初回は`lights-spike-rt.zip`を使ってください。

ZIP内のファイルをSPIKE-RT v0.2.0の`user_apps/app/`へ配置します。具体的なビルド手順はZIP内の`BUILD.md`にあります。標準Hub OSへのBluetooth転送ではSPIKE-RTを書き込めません。

## 構成

| ファイル | 役割 |
|---|---|
| `app.js`, `index.html`, `style.css` | 画面・作品保存・操作 |
| `blocks.js` | ブロックと共通命令データの変換 |
| `model.js` | 共通命令データ・検証・お手本 |
| `generate.js` | Python / SPIKE-RT C生成 |
| `spike-ble.js` | SPIKE App 3のBLE通信 |
| `zip.js` | CRC32 / ZIP出力 |
| `rt-template.cdl`, `RT-NOTICE.txt` | SPIKE-RT構成と出典 |
| `*.test.mjs` | 自動試験 |
