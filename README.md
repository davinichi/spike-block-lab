# SPIKE Block Lab

Chromebook・WindowsのブラウザーからLEGO Education SPIKE PrimeをプログラミングするWebアプリです。ブロックで作ったプログラムをPythonへ変換し、本体に保存して動かします。

**公開中のアプリと、このリポジトリの収録ソースはv1.1.0運用版です。**

更新日：2026年11月28日。

## v1.0の運用方針

SBLは授業での安定した利用を優先し、当面は機能追加を休止します。不具合は随時修正し、既存作品の互換性を維持します。運用版への移行は、全機能の実機確認完了を意味しません。

EBL、EBL-RT Web版、EBL-RT Windowsアプリはプレビュー版として開発を継続します。SPIKE-RTについては将来SBLへ統合する構想がありますが、現時点でSBLからSPIKE-RT向けのプログラムを生成・転送する機能はありません。別のSPIKE-RTリポジトリは現状を維持します。

開発の目的は、基本のプログラミングから計測・データ処理へ学びを広げることです。Windows PCの老朽化を理由に開発したものではありません。

## 公開版v1.0.1の主な機能

以下は公開サイトと、このリポジトリのv1.0.1ソースの機能です。

- 左右モーターの共通設定、距離移動、スピン・ピボット、ジャイロ旋回・直進。
- モーター単独制御、回転方向を個別設定する専用同期、絶対角度指定（360度は0度）。
- 時間／距離比率による加減速、未設定時8％の最低速度、速度入力・計算結果の−100〜100％制限。
- 接続ポートの機器と現在値、反射光、本体ジャイロ角度・角速度・加速度の表示・利用。
- 条件・繰り返し・演算・PID・データ・変数・CSV記録、最大8個の名前付き戻り値を持つマイブロック。
- 「表示」へのランプ統合。マイブロックは赤、変数はオレンジ。定義を右クリックして編集。
- ブロックとPythonの左右比較、自動更新、表示幅の調整。作ったPythonと内部処理を分離し、転送時に結合。
- 日本語／英語、Bluetooth／USBケーブル接続、教員向けの本体保存番号指定による削除確認。
- 教員向け資料を「教員・指導者用」へ集約。上部の「ヒント・お知らせ」、操作の近くのエラー・保存通知、下部の詳しい通信ログ。

PID走行・左右同期の専用記録はデバッグ版向けです。通常の公開一覧には出しませんが、旧作品を読み込む処理は維持します。ジャイロ初期化はドリフトを完全に防止するものではありません。

## 数値欄の全角・半角（v1.0.1）

全角の数字・マイナス・小数点を半角に自動変換します。例：`－１２．５` → `-12.5`。編集エリア上部に「半角に直しました」と約4秒表示します。IME変換中は書き換えず確定後に処理し、変数名・マイブロック名・文字列は変更しません。既存の数値制約と保存形式は維持しています。

## 作品の保存と実行

「保存」は編集用の `.spikelab` ファイルを端末へダウンロードする操作です。本体への転送とは異なります。自動保存は同じブラウザー・サイト内の保存で、クラウド保存ではありません。

「動き」を使うときは、先に共通設定ブロックで左右モーターを指定します。単独モーターは各ブロックでポートを指定します。公開サイトの「教員・指導者用」から操作手順とマニュアルを確認してください。

LEGO純正の `.llsp3` やEBLの `.ev3lab` との直接互換性はありません。生成した `program.py` は内部処理と結合して実行する構成で、単独実行用ではありません。

# SPIKE Block Lab

ChromebookでLEGO Education SPIKE PRIMEをプログラミングするWebアプリ。**v0.7.0・標準Hub OS向け・一部実機確認済みの試作版**です。SPIKE-RT用ソースコード生成は将来の発展目標です。

## EV3 Block Labと共通の操作

[EV3 Block Lab v0.22.0](https://github.com/davinichi/ev3-block-lab)の分類・順序・表現を基準にしています。

スタート → イベント → モーター → 動き → センサー → 音 → 制御 → 演算 → 表示 → ランプ → データ → 記録 → 変数 → マイブロック → 引数。

- **モーター**：1個／2個、回し続ける／角度／回転数／秒、停止方法を分けています。SPIKEのL/Mモーターに共通です。
- **動き**：前進・後退、右／左スピンターン、右／左ピボットターンを別ブロックにしました。最初に左右のモーターポートを設定し、以降の動きとマイブロックで共有します。タイヤ直径・トレッドを設定できます。
- **発展の動き**：ステアリング、左右別の速さ。連続・角度・秒指定を分けています。ステアリングの数値は車体の旋回角度ではありません。
- **センサー**：タイマー、エンコーダ、本体姿勢・ボタン、フォース、カラー、距離。比較条件を直接作れるブロックがあります。
- **制御・演算**：条件・繰り返し・待つ・終了、PID、四則演算と比較を分けたパレット、数学関数、乱数、丸め、範囲制限。
- **表示・ランプ・音**：5×5ライト、英数字・数値・そろばん表示、ランプ色・消灯・点滅・明暗、本体スピーカーの周波数・ミリ秒・音量。
- **データ・記録**：名前付き文字、数値リストの操作と統計、本体へのCSV保存と再接続後の取得、変数。
- **マイブロック・引数**：定義と呼び出し、独立した引数グループ、引数付き呼び出し、定義内の終了。

上部の保存・開く・マイブロック、中央のBlockly、右の接続・転送パネル、下部の通信ログはEV3版と同じ流れです。

## 更新時の注意

v0.3.0ではオーナーの指示により旧作品との互換性維持を優先せず、旧形式の動き・モーター・音ブロックを整理しています。旧作品は新しいブロックで組み直してください。更新前に必要な作品は保存してください。

「保存」は編集可能な作品、本体への転送は選んだ番号への上書きです。転送前に保存先の旧プログラムを消します。途中失敗で元のプログラムは復元されません。転送成功はCRC付き要求への本体応答の確認で、全バイト読み戻し照合とは異なります。実行成功や車体の精度は実機で確認します。

新しい旋回はエンコーダと幾何計算を使用します。スピンのモーター角度＝トレッド÷直径×車体角度、ピボットはその2倍。タイヤ直結・標準的な左右取り付けを想定し、床・負荷・滑りによる誤差は補正しません。
