# SPIKE Block Lab

ChromebookでLEGO Education SPIKE PRIMEをプログラミングするWebアプリ。**v0.4.6・標準Hub OS向け・一部実機確認済みの試作版**です。SPIKE-RT用ソースコード生成は将来の発展目標です。

## EV3 Block Labと共通の操作

[EV3 Block Lab v0.22.0](https://github.com/davinichi/ev3-block-lab)の分類・順序・表現を基準にしています。

スタート → イベント → モーター → 動き → センサー → 音 → 制御 → 演算 → 表示 → ランプ → データ → 記録 → 変数 → マイブロック → 引数。

- **モーター**：1個／2個、回し続ける／角度／回転数／秒、停止方法を分けています。SPIKEのL/Mモーターに共通です。
- **動き**：前進・後退、右／左スピンターン、右／左ピボットターンを別ブロックにしました。各命令でモーターポートを指定します。タイヤ直径・トレッドを設定できます。
- **発展の動き**：ステアリング、左右別の速さ。連続・角度・秒指定を分けています。ステアリングの数値は車体の旋回角度ではありません。
- **センサー**：タイマー、エンコーダ、本体姿勢・ボタン、フォース、カラー、距離。比較条件を直接作れるブロックがあります。
- **制御・演算**：条件・繰り返し・待つ・終了、PID、四則演算と比較を分けたパレット、数学関数、乱数、丸め、範囲制限。
- **表示・ランプ・音**：5×5ライト、英数字・絵・数値、ランプ色・消灯・点滅・明暗、本体スピーカーの周波数・ミリ秒・音量。
- **データ・記録**：名前付き文字、数値リストの操作と統計、本体へのCSV保存と再接続後の取得、変数。
- **マイブロック・引数**：定義と呼び出し、独立した引数グループ、引数付き呼び出し、定義内の終了。

上部の保存・開く・マイブロック、中央のBlockly、右の接続・転送パネル、下部の通信ログはEV3版と同じ流れです。

## SPIKE本体による違い

| EV3版 | SPIKE版 |
| --- | --- |
| 178×128ドット画面 | 「表示」グループの5×5ライト。英数字・記号。日本語画像化、文字サイズ・画面座標はありません。 |
| タッチセンサ・外付けジャイロ | フォースセンサ・本体姿勢に置き換えます。 |
| 赤外線、電圧・電流 | 本体の電圧はmVで取得。赤外線・電流のブロックは用意していません。 |
| L/M別のモーター命令 | SPIKE L/M共通。2個指定は各軸を同方向に回します。車体の移動は「動き」を使います。 |
| 加減速プロファイル・同期補正 | SPIKE用の台形・S字加減速、20msエンコーダ同期補正を追加。実機確認待ちです。 |
| 本体ファイルへのCSV記録 | 本体ファイルに保存し、再接続後にCSVとして取得。ファイルAPI対応と再起動後の保持は実機確認待ちです。 |

画面構成の統一は全機能・作品形式の互換性を意味しません。EV3用の全テキスト／リスト命令の移植、.llsp3、.ev3labの互換性、USB転送、公式教材・素材には対応していません。

## 起動・確認

Node.js 24以上、Python 3を使います。

```sh
npm ci
npm test
npm run build
npm start
```

Chromeで http://127.0.0.1:8766/ を開きます。公開用ファイルは`dist/`。HTTPSとBluetooth接続許可が必要です。Blocklyはローカル同梱でCDNに依存しません。

自動試験34件が成功。実際のBlocklyでの全ブロック構築・保存・復元、11サンプルのPython構文、前進／後退／スピン／ピボットの引数と幾何計算、名前付きリスト・PID、転送・CRC・切断・エラーを確認します。ブラウザで分類・入力・サンプル表示を確認しています。自動試験は実機確認の代わりではありません。

`npm run export:sample`で`generated/standard/`に14種類のPythonと編集可能な作品を出力します。

## 更新時の注意

v0.3.0ではオーナーの指示により旧作品との互換性維持を優先せず、旧形式の動き・モーター・音ブロックを整理しています。旧作品は新しいブロックで組み直してください。更新前に必要な作品は保存してください。

「保存」は編集可能な作品、本体への転送は選んだ番号への上書きです。転送前に保存先の旧プログラムを消します。途中失敗で元のプログラムは復元されません。転送成功はCRC付き要求への本体応答の確認で、全バイト読み戻し照合とは異なります。実行成功や車体の精度は実機で確認します。

新しい旋回はエンコーダと幾何計算を使用します。スピンのモーター角度＝トレッド÷直径×車体角度、ピボットはその2倍。タイヤ直結・標準的な左右取り付けを想定し、床・負荷・滑りによる誤差は補正しません。

## ソース

`app.js`：画面・保存・転送、`classroom-blocks.js`：SPIKE基本ブロック、`common-blocks.js`：共通の分類・命令・引数、`standard.js`と`common-runtime.js`：本体Python生成、`classroom-samples.js`：11サンプル、`spike-ble.js`：BLE転送、`model.js`：保存検証。`generate.js`と`rt-template.cdl`は将来のSPIKE-RT用初期検討で、現在の画面には出しません。

LEGO公式アプリではありません。独自コードの公開ライセンスは未設定です。出典は[THIRD_PARTY.md](THIRD_PARTY.md)。元のEV3リポジトリは変更していません。

## v0.4.1 マイブロック作成・編集の統一

EV3版と同じフォームへ統一しました。「＋ 引数を追加」と行ごとの「削除」で設定し、作成後は一覧の「編集」または定義の右クリック「名前・引数を編集」から再編集します。Blocklyの歯車による編集は使いません。呼び出しブロックの入力式を引数の識別子に対応付けて保持し、使っている引数の削除はエラーにします。名前の重複、引数8個・マイブロック32個の上限を検証します。マニュアルもv0.4.1へ更新しました。


## v0.4.1 比較表の1〜6への対応

1. 制御の形と色、固定記号の演算、変数作成、後続を含む複製、パレット開閉をEBLに統一。
2. メッセージ送信完了待ち、待ち循環の検出、丸め（floor(x+0.5)）、空リスト統計を統一。
3. 実測速度・停止設定・目標保持の速度変更・PWMパワーを追加。
4. 文字位置・包含・一致・数値変換、数学関数14種・2数min/max、ランプ点滅・明暗を追加。
5. 切断中の本体CSV保存、再接続後の取得を追加。ファイルAPI非対応時は明示エラー。読み出し用スロット（初期値19）を上書きする確認があります。CSVは削除しません。
6. 台形・S字プロファイルと20msエンコーダ同期補正を追加。標準の動きは公式motor_pairを使用し、プロファイル・停止設定・速度変更・同期指定時は目標を管理するSPIKE用ループへ切り替えます。

追加機能は実機未確認です。CSVファイル保存APIの対応・電源再投入後の保持、PWM、明暗の見え方、左右方向・停止精度・速度変更をTESTING.mdに沿って確認します。明暗は色のHSV指定に依存せず、点灯時間を変える方式です。ネイティブEV3同期命令との同一精度は保証しません。


## v0.4.1 電圧・そろばん表示

- 加減速・同期補正は「モーター」グループに配置しました。
- 「センサー」に本体のバッテリー電圧（mV）を追加。ユーザー提供プログラムと同じ `hub.battery_voltage()` を使用します。未対応のHub OSでは明示エラー。
- 「表示」に0〜99999の整数をそろばん形式で表示する命令を追加。右詰め、最上段は5、下4段は1。0は無点灯。小数・負数・6桁以上はエラー。
- サンプル「電圧をそろばん表示」（BatteryAbacus）：左ボタンを待つ→262Hzを1秒→電圧mVを表示。計測・描画は本体上で実行します。実機確認はオーナー担当です。


## v0.4.2 転送・実行の操作

EBLと同様に、転送・転送して実行・再実行は確認ポップアップなしで操作できます。上書きする番号と転送後すぐ動く説明は、接続・転送パネル内に表示します。作品を置き換える操作とCSV読み出し用スロットの上書き確認は別の操作として残します。


## v0.4.3 小さいウインドウの表示

接続パネルは編集画面に重ねず、横に場所を確保します。幅640px以下では縦に配置します。ツールバーは必要に応じて折り返し、編集領域のサイズ変更時にBlocklyを再計算します。


## v0.4.4 マイブロックの呼び出し表示

EBLと同じく、マイブロックの呼び出しは名前と引数を横一列に表示します。縦並びで保存された作品も、読み込み時に横並びへそろえます。


## v0.4.5 通信ログの消去

通信ログの「ログを保存」の隣に「ログを消去」を追加。表示と保存対象の履歴を空にします。本体のCSV記録は対象外です。

実機確認：v0.4.4で左B・右A、タイヤ直径56mm、マイブロック引数50％・30cmの前進、およびランプの色指定後に待機を置いた動作をオーナーが確認しました。


## v0.4.6 センサー通知のエラー処理

センサー通知の解析エラーでBluetoothを切断していた処理を修正。接続を維持し、値を未取得に戻して状況を表示します。読み取れなかった通知の形式・長さ・生データを、更新開始ごとに1回だけ通信ログへ記録します。Hub OS 1.8.149の通知形式の実機確認を継続します。
