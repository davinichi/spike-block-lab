v1.0の運用方針
SBLは運用版です。当面は機能追加を休止し、不具合修正を随時行います。
エラー・保存通知
プログラムのエラーは編集エリア上部に表示し、該当ブロックを特定できる場合は強調します。修正すると表示が消えます。接続・転送のエラーは操作ボタンの近く、保存結果は「保存」の近くに表示します。保存ファイルのダウンロード開始通知は約5秒で消え、エラーは残ります。詳しい通信ログは画面下部で確認できます。
Chromebookから、SPIKEへ。
EV3 Block Labと同じ流れで、ブロックをつなぎ、本体に保存して試します。対象はSPIKE App 3対応の標準Hub OSです。
画面の使い方
「接続・転送」で右パネルを開きます。「閉じる」で編集画面全体を使えます。「保存」は後から編集できる作品ファイルです。本体への転送とは別に、授業の区切りで保存してください。
ブロックとPythonを見比べる
「教員・指導者用」→「Pythonを見る」で左にブロック、右にPythonを表示します。境界をドラッグするか、境界にTabで移動して左右キーで幅を調整できます。「スタートのコードへ」はPython表示を最初のスタートやイベントのコードまでスクロールするボタンです。プログラムを実行する操作ではありません。表示専用で、ブロック変更・元に戻す・作品読込に合わせて自動更新します。エラー時は古いコードを消し、理由を表示します。「閉じる」またはEscで全幅の編集へ戻ります。接続・転送欄とは切り替え表示し、接続は維持します。
本体のプログラムを削除
本体へ接続後、「教員・指導者用」→「本体のプログラムを削除」で0〜19から番号を選びます。接続先と番号を確認して削除してください。保存済み一覧・名前は取得できません。削除は元に戻せず、PCの作品は残ります。実機での削除は未確認です。
距離センサーのランプと本体ジャイロ
「表示」の距離センサーのランプは0％で消灯、100％で最大です。「センサー」の本体ジャイロは向き・前後の傾き・左右の傾きを度で読みます。X・Y・Z軸の角速度（度/秒）と加速度（mG）も取得できます。1000mG＝1Gで、加速度は重力を含みます。静止確認付き初期化は、3軸の角度変動が0.5度以内で1秒続いたら向きだけ0にします。本体を静止させ、最大待ち時間は1.1〜30秒で指定します。姿勢の基準合わせを助けますが、走行中のドリフト防止や内部校正ではありません。距離センサーにジャイロは内蔵されていません。追加機能は実機未確認です。
接続機器と現在値
「接続・転送」を開いて接続すると、ポートA〜Fの機器と値を約0.5秒ごとに更新します。カラーセンサーは色名・色番号・反射光を表示します。旧形式で反射光の通知がない場合は未取得と明示します。「更新を止める」で停止、「値を読む・更新」で再開。3秒以上通知がない場合や読取りエラー時は前回の値と示し、切断時は消去します。確認用のプログラム転送や本体番号の上書きはありません。
接続して動かす
  1. 接続方法を選ぶ。Bluetoothでは本体のBluetoothボタンを押し、USBではデータ通信対応ケーブルでつなぐ
  2. 「接続する」から本体を選ぶ
  3. 保存番号を確認し、「SPIKEに転送」を押す
  4. 接続したまま動かす場合は「転送して実行」を押す
「転送して実行」は転送後すぐ動きます。ブラウザの停止は接続中だけ使えます。本体の停止操作を初めに確認してください。
SPIKEだけで動かす
PCから切り離して動かす場合の手順です。接続したまま「転送して実行」で試す場合、切断は不要です。
  1. 転送完了を確認する
  2. 「切断」を押す
  3. ケーブルを接続している場合は、ケーブルもはずす
  4. 本体で保存番号を選び、中央ボタンで実行する
モーター・動き
速さは−100〜100％です。100％を1050度/秒に換算します。「動き」には前進・後退・スピンターン・ピボットターンを別々に用意しています。「スタート」の直後に「動きに使うモーターを 左B 右C にする」を置き、実際の配線に合わせます。以降の前進・後退・旋回とマイブロック内の動きも、その共通設定を使います。途中で同じ設定ブロックを実行すると、以前の左右モーターを停止して切り替えます。設定だけでは回りません。単独・2個の「モーター」ブロックには個別のポート指定を残しています。距離移動には実際のタイヤ直径、旋回にはトレッドも設定してください。
マイブロック
上部のボタンで名前と引数を設定します。定義ブロックの中へ命令を入れ、「マイブロック」から呼び出します。引数は「引数」グループから取り出して定義の中で使います。「戻り値なし」は命令をまとめます。「数値を返す」は最大8個の戻り値に名前を付け、定義の各「返す値」に計算式を入れます。丸い呼び出しは数値欄へ入れ、使う戻り値を選びます。呼び出すたびに定義を実行します。全戻り値を1回で受け取る場合は、変数へ受け取る呼び出しを使います。「値を返して終了する」は定義の途中で戻ります。戻り値の有無・個数を変える前に呼び出しを削除し、編集後に置き直します。未接続ブロックと未使用の定義は転送しません。
加減速の時間と最低速度
加速時間は最低速度から指定最高速度まで、減速時間は最高速度から最低速度までの速度指令の変化時間です。例えば最低8％・最高50％・減速0.1秒なら、指令を約0.1秒で50％から8％へ下げます。実速度が同じ時間で追従する保証はありません。台形・S字を選べ、0秒は即時変更。角度・距離指定では応答遅れを開始位置へ反映し、設定時間を引き延ばしません。短い動作では最高速度に届かず、時間を縮める場合があります。
最低速度は初期8％です。モーター末尾の「加減速の最低速度を○％にする」で共通設定します。時間指定にも適用します。指定最高速度は超えません。連続運転・絶対角度は対象外です。角度指定の終端で約0.4秒ほぼ回らなければ停止してエラーを通知します。
距離の比率で加減速
秒指定とは別の「距離の比率で加減速」を使います。100cm・加速区間10％・減速区間10％なら、最初の10cmで最低速度から最高速度へ、最後の10cmで最低速度へ下げます。中間80cmは最高速度です。各0〜100％、合計100％以下。後から実行した加減速設定を使います。時間指定の動作では秒指定へ切り替えてください。サンプル「距離比率で加減速（10％・10％）」を追加しました。比率は軸回転量から求めた指令区間で、床上の実距離や実速度の追従を保証しません。
作ったPythonと内部処理
Python表示は最初に「作ったプログラム」を表示し、「内部処理」で共通処理へ切り替えます。日本語コメントを付け、マイブロックの引数はPythonで使える名前をそのまま残します。記号・予約語や重複は安全な別名へ変換します。「Pythonを保存（2ファイル）」でprogram.pyとsbl_runtime.pyを説明書とともにZIP保存できます。転送時は同じ名前空間で1つに結合します。program.py単独では動きません。結合済みの1ファイル保存も選べます。
EBL・EBL-RTと共通の操作
音・制御・演算・データ・記録・変数・マイブロック・引数の基本ブロックと並びを共通化しました。音は250〜10000Hz・1〜30000ミリ秒、音量は0〜100の固定欄です。演算の余り・乱数・最小・最大・四捨五入・範囲制限は別ブロックです。文字列はUTF-8で120バイト以内、日本語も文字数を数えられます。番号は1から、文字数を超える位置は空文字。通常の数値変数は開始時0、文字列変数は空文字、数値リストは空です。引数専用の名前は通常変数の一覧から除きます。PIDは同じミリ秒の再計算では前回値、60秒を超える中断後はP項から再開します。
「CSVログ」の開始・値記録・終了はEBLと同じ表現です。SBLは1000行・32KiBをメモリへ蓄え、モーター停止後に終了ブロックで保存します。EBLと保存方法・CSV列名・上限は異なります。同期の自動記録はSPIKE固有の追加です。旧ブロックを含む既存作品は読込可能ですが、EBL・EBL-RTの作品ファイルを直接読み込む機能ではありません。負数の余りはEBL基準（−5を3で割った余りは1）。比較対象のEBL-RTには符号の差が残るため、マニュアルの差分をご覧ください。
記録と同期の確認
記録は最大1000行・32KiBをメモリに蓄えます。電源を切る前に、モーターを停止してから「記録を終える」でCSVを保存します。「左右モーターの同期を100ミリ秒ごとに記録する」は角度差・実速度・速度指令・加速／減速の区間を同じ採取時刻で記録します。実速度は角度差÷実際の採取間隔で計算し、初回は空欄です。「同期確認」の3サンプルで有効・無効を比較できます。同期補正は先行量を約200msで平滑化し、4度以内は補正せず、先行側だけ最大3％減速します。4度を超えた分は1度あたり0.15％、補正指令の変化を毎秒31.5度/秒以内に抑えます。最低速度8％を下回らせず、加減速カーブは引き延ばしません。サンプル「同期確認：80％・100cm・各20％」はS字・最低8％・同期有効・100ms記録です。実物に合わせて左右ポートを直し、有効／無効を同じ条件で比較してください。タイヤの滑り・方位・大きな機械差は補正できず、実機のふらつき低減は未確認です。
モーター1個と2個の同期
モーターグループはL・Mを分けず、1個の操作と専用同期に整理しました。「同期するモーターを A［正方向］とB［逆方向］にする」を先に置き、同期の連続・角度・回転数・時間・停止を使います。負の速さでは両軸が設定と逆に回ります。「動き」の左右設定は別です。専用同期の補正は常に有効で、加減速は有限動作に適用します。連続同期中に片方を個別操作すると、もう片方は停止します。旧2個指定やL/M別のブロックは新規一覧から外しましたが、保存済み作品から読み込めます。サンプル「2個を同期（正方向・逆方向）」で試せます。実機未確認です。
絶対角度
SPIKE固有の絶対角度は0〜360度（360度は0度）、速さ1〜100％、最短・時計回り・反時計回りを選びます。共通の加減速・同期補正ではなく本体標準の位置制御です。
距離の条件
対象なし・測定範囲外では、専用の距離条件は「＞・≧・≠」を真、「＜・≦・＝」を偽にします。「距離＞15cmの間」は対象なしでも動きます。実際に測定できたかは「測れている」で確認します。機器の未接続エラーはそのまま表示します。
PIDの周期と記録
命令ごとの固定10ミリ秒待ちを廃止しました。「0.02秒待つ」は全体の周期保証ではなく、計算や本体APIの時間も加わります。「記録」の「PID走行を○ミリ秒ごとに記録する」はループ内でモーター指示の後に置き、計算済みの反射光・PID出力・左右速度を入れます。同時刻の5行で制御周期の目安も記録。まず3秒・100ms記録で確認し、120秒では1000ms記録を出発点にします。記録名と取り出し名を合わせてください。周期が短くなるため、保存済みのゲインでの実機追従性は再確認が必要です。
並行処理と表示
複数のスタートは本体で並行して動きます。条件イベントは成立したときに1回動き、条件が戻ると次の成立で動きます。本体の文字表示は英数字・記号です。
SPIKEにはEV3のようなディスプレイがないため、画像ブロックは一覧から外しています。「表示」では5×5ライトの点灯・消灯、英数字・数値・そろばん表示を使います。今後の学びと開発の発展、SPIKE-RTとの連携を見据えて育てるアプリです。SPIKE-RT用の生成・転送は将来構想であり、現在は標準Hub OSで動作します。
