# SBL 次期バージョンの変更候補

更新日：2026年11月27日。現行版はv1.0.1です。以下は授業から得た追加候補で、実装・公開時期は未定です。現行版は運用と不具合修正を優先し、この記録だけで機能追加を開始するものではありません。

## バッテリー電流を調べるブロック

状態：候補・標準Hub OSでの取得方法は未確認。

- 本体のバッテリー電流を数値として読み取り、表示・条件判定・CSV記録に使えるようにする。
- 単位は取得APIの仕様を確認して明記する。mAで取得できる場合はmAと表示する。
- 本体全体の電流と、個々のモーターの電流を区別する。モーター別の電流が読めると推測して実装しない。
- 現在の標準Hub OSに対応するAPI、単位、更新間隔、USB給電・充電中の意味、対応しない場合の通知を調査する。
- モーター停止中・動作中で値を比較し、取得APIと実機の挙動を確認してから追加する。
- SPIKE-RTの `hub_battery_get_current()` はmAを返すが、標準Hub OS用SBLへそのまま使えることを意味しない。

参考：[SPIKE-RT公式のバッテリーAPI](https://spike-rt.github.io/spike-rt/ja/html/group__Battery.html)、[LEGO旧ハブAPIの電流取得](https://lego.github.io/MINDSTORMS-Robot-Inventor-hub-API/mod_battery.html)。旧APIは現行Hub OSへの対応保証ではありません。

## 距離センサーのライトを4か所別々に操作するブロック

状態：候補・ライト位置とAPI配列順の実機確認が必要。

- 「表示」グループに、距離センサーのポートと左上・左下・右上・右下それぞれの明るさを指定するブロックを検討する。
- 各位置の明るさは0〜100％を想定。0％は消灯、100％は最大点灯とする。
- 例：左上100％・左下0％・右上0％・右下100％。
- SPIKEアプリのように位置が分かる表示を検討する。
- 既存の「4か所を同じ明るさにする」ブロックと、既存作品の読込・動作を維持する。
- センサー正面から見た位置、APIの配列順、明るさ、点灯を保った距離読取り、未接続・別機器・範囲外の扱いを実機で確認する。
