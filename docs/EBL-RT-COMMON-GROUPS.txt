EBL / EBL-RT 共通グループ統一指示書（SBL v0.9.0、2026-11-23）

対象：音、制御、演算、データ、記録、変数、マイブロック、引数。
比較済み：EBL v0.25.6、EBL-RT編集画面 v0.34.2-ev3rt.1（Windows配布版0.3.5）。以降の版は未確認。
SBL側を修正・検証。EBL / EBL-RT側のソース自体は今回変更していない。

1. 境界動作の統一
余りはEBL標準の「除数の符号」を共通基準にする。
期待値：-5 % 3 = 1、5 % -3 = -1、-5 % -3 = -2、5 % 3 = 2、5.5 % 2 = 1.5。
EBL-RTのev3rt.jsはfmodf(a,b)をそのまま返す。r=fmodf(a,b)の後、r!=0かつrとbの符号が異なる場合にr+=bとする。0除算は拒否する。
整数乱数は両端を含む-32767〜32767、下限<=上限。小数・NaN・無限大を認めない。EBL標準は整数オペランド化で小数を切り捨てるため、変換前に整数性を検査する。EBL-RTとSBLは小数を拒否。
四捨五入はfloor(x+0.5)。-1.5→-1、-0.5→0。乱数列の一致は求めず、範囲を揃える。
内部精度や三角関数の最終ビットは環境差として、比較に許容誤差を付ける。

2. 公開ブロックの順序・操作
音：周波数(Hz)、長さ(ms)、固定音量欄。250〜10000Hz、1〜30000ms、音量0〜100。完了を待つ。
制御：秒待つ、if、if/else、ずっと、回数、until、while、条件待ち、全体終了、定義終了、PID、PIDリセット。
演算：数値、四則、数学関数、比較6種、かつ/または、否定、真偽、余り/乱数/最小/最大/四捨五入/範囲制限。
データ：文字列、文字列変数の取得/設定、2入力結合、文字数、1文字、含む/一致、数値→文字列/文字列→数値、数値リスト8操作。
記録：CSV開始、項目・値、CSV終了。SBL同期自動記録は固有拡張として末尾に区切る。
変数：作成、代入、増減、名前ごとの取得。引数専用モデルを除き、定義外の通常変数として使う既存同名モデルは残す。
マイブロック：作成・編集・呼出し・数値早期return。最大8引数・8名前付き数値戻り値・32定義。全戻り値を一度で普通の変数へ受け取る呼出しも整合対象。
引数：定義内だけで使い、同名は一覧で1つにまとめ、配置先定義で解決する。定義外使用は転送前に拒否する。

3. データ共通仕様
文字列はUTF-8で120バイト以内、NUL禁止。文字数はUnicodeコードポイント数。
文字位置は1〜120の整数。文字数を超える位置は空文字。リスト位置は存在する1〜項目数、最大1000項目。
数値→文字列は有効数字7桁。文字列→数値は十進数と指数表記。空白・単位・16進数・NaN/Infinity・数字内の_は拒否。
通常数値変数は開始時0、文字列変数は空文字、リストは空。
PID：初回Pのみ、同じミリ秒は前回出力。60秒超の中断後は積分を捨てPのみ。出力は自動制限せず利用側でclampする。

4. 維持する実装差
SBLは32KiB/1000行のRAM記録を停止後/flashへ保存。EBL標準は行ごと、EBL-RTはSDへ保存。性能・記憶媒体が異なるため方式を無理に揃えない。
CSVはSBLがtime_s,label,value、EBL系がtime_s,item,value。labelとitemは同じ項目名。取込み側で両列名を受け付け、既存ファイルは書き換えない。
SBLの最低8％、距離比率、弱い同期補正をEBL系へそのまま移植しない。音質・体感音量・PID走行性能は各実機で確認する。

5. 回帰テスト
余り5例、0除算、乱数の小数/範囲外、負数丸め、UTF-8上限、日本語位置、文字数超過、厳密数値変換、空リスト統計、PID同一ms/60秒超。
8引数・8戻り値、出力選択、早期return、1回で複数値受取り、同名引数、通常変数の除外と復元、保存→新規読込→生成。
過去の戻り値なし作品と旧ブロックを読み、入力式と接続を保持する。
