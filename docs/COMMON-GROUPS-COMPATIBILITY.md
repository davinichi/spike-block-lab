# SBL v0.9.0 共通グループ

比較元はshared-groups-reference.jsonに固定。EBL v0.25.6 / EBL-RT editor v0.34.2-ev3rt.1、Windows package 0.3.5。extract-shared-reference.mjsは比較元を読取専用で抽出する開発用ツールで、配信しない。

音・制御・演算・データ・記録の基本パレットは、型名対応後の一覧と既定値を両参照へ自動比較。SBLの左右同期記録は記録の末尾へ固有拡張として残す。変数・マイブロック・引数は動的パレットを検証。

既存型とフィールド・入力名を維持。固定音量の音、固定2入力の文字列と数値演算は別型で定義し、旧作品は旧型のまま読める。保存形式version=1を維持。EBL作品やネイティブ実行ファイルへの相互変換は対象外。

通常の数値変数の初期値をNoneから0へ揃える。引数専用変数を通常一覧と選択肢から除き、定義外の既存同名使用は残す。文字列変数・リスト・PIDの名前は1〜40文字、各16種類を転送前に検査。新しい計算と数値代入は有限数値を検査。PIDは60秒超の中断後に積分をリセット。

CSVは1000行・32KiBのRAMバッファと停止後保存、既存列名labelを維持。EBL系のitemと意味は同じ。モーター・同期補正・最低速度・距離比率の計算コードは変更しない。

EBL-RTの負数余りとEBL標準の小数乱数入力は参照元同士に差が残る。SBLの余りはEBL標準基準、乱数はEBL-RTの整数入力基準。残差と修正手順はEBL-RT-COMMON-GROUPS.txtへ記載。参照元の改変・EBL-RT配布は今回実施しない。

実機未確認：新共通音ブロックの本体実行、文字列とCSVの通し操作、PID走行性能。保存読込・生成・模擬Hub実行で検証する。
