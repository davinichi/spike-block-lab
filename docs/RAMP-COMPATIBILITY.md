# 加減速の基本曲線とSBLの緩和した同期補正（v0.8.7）

基本曲線の基準はEBL v0.25.6。参照ソースSHA-256: 9e672221bcc9b7c2ce7afc29678831faef9fe03bbdb48b53f9fc387f0e13650c。

現行の時間定義はv0.8.6の節を参照。EBLと共通なのはQ1000の曲線値です。最低8％を基点とした時間定義へ変更したため、旧EBL指令列との完全一致の判定は廃止しています。過去の参照データは履歴として保持します。

ユーザーの実機CSVで旧補正の片側0指令や左右交互の指令低下を確認したため、同期有効時はSBL独自の緩和制御とします。進み量は指定速度比で正規化し、先行量を一次平滑化（係数0.25）。1度の不感帯を超えた差1度あたり2％の相対減速、最大15％。名目指令5％以下では同期減速を解除します。

同期有効な2軸の指令には525度/秒²の変化制限を適用します（20msで約10.5度/秒、整数丸めあり）。制御周期の実測値を使い、50msを超える遅れでは変化幅を50ms分に制限。最初の始動、方向指定の変更、速度0、目標位置到達、明示停止は優先します。非ゼロの名目指令を同期補正だけで0にはしません。低速での実際の回転や負荷への追従を保証するものではありません。

速度の記録は本体API motor.velocity()の値を使用せず、連続する採取時刻間の角度変化から度/秒を算出します。初回は空欄。角度差分の区間平均なので、同時刻の瞬間速度指令とは異なります。

非対称応答・遅れ・符号反転を模擬した完走試験、指令変化幅、低速時の非ゼロ、補正上限、記録の単位を検証します。実機のふらつき改善は再確認が必要です。


## v0.8.2 角度・距離指定の早期減速
減速時間が正で加減速有効な有限動作が対象。約60ms以上の実測角度差分から軸速度を求め、速度比で正規化した実測値と直前指令の大きい方vを採用します。左右のうち先に目標へ達する軸の残り距離を判定に使います。

減速時間Dは設定値の現在速度への縮小値と、指令変化制限525度/秒²に必要な時間の大きい方。S字は最大傾斜を考え1.5倍の時間を確保します。距離はvD/2＋v（応答遅れ＋制御周期余裕）＋角度余裕。応答遅れは初期500ms、減速中の実測速度と指令差・指令下降率から推定し最大1000msまで延長します。制御周期余裕40～200ms、角度余裕max(2度, v×0.02秒)。これは保守的な予測であり、実機の遅れの保証値ではありません。

減速中は残り角度に基づくv²/(2a)＋遅れ分の上限も適用し、上限を再上昇させません。終端は最大3％で目標へ接近します。目標到達・明示停止は最優先です。時間指定、加減速なし、減速0はこの変更の対象外。走行時間が延びることがあり、低速で回らない負荷では既存タイムアウトが停止させます。

96条件（台形/S字、20/50％、100/614/2046度、応答遅れ80/150/300/500ms、同期有効/無効）の非対称応答を模擬。目標到達、停止前指令32度/秒以下、停止前模擬実速度50度/秒以下、同期有効時の指令変化幅を検証。実機は未確認です。


## v0.8.3 安定する最低速度の設定
角度・回転数・距離指定の加減速に共通の最低速度を設けます。標準8％、新ブロック「加減速の最低速度を○％にする」で1〜100％へ設定可能。旧作品にブロックがなくても8％を使います。安定速度の自動検出ではなく機体・負荷に応じて実機で調整する設定です。

従来の終端3％を廃止し、最低速度から加速、最低速度へ向けて台形/S字で減速。予測距離は(v＋最低速度)D/2へ修正。先行側の同期減速も軸ごとの最低速度で制限。左右速度比を維持するため、遅い軸が最低速度になるよう共通上限を計算します。指定最高速度を超えて増速せず、指定速度自体が低い場合の安定回転は保証しません。時間指定・加減速なし・連続運転・絶対角度は対象外です。速度0・目標到達・明示停止は優先します。

8％は実機で確定した最小値ではありません。8→10→12％と調整し、減速時の実速度と動画を確認します。負荷・電圧・取り付けが変われば再調整が必要です。

既存96条件を最低速度8％で再検証し、目標到達・停止直前指令84度/秒以下・模擬実速度105度/秒以下を確認。追加24条件では63度/秒未満で停止と突発回転を繰り返す模擬モデルを使い、旧3％で症状を再現、8/12％でその領域へ入らず完走することを確認。台形/S字、単軸/二軸、逆転、左右速度比を含みます。実機の滑らかさは未確認です。

終端速度域で400ms以上、角度変化2度未満の場合は全選択軸を停止し、最低速度または負荷の見直しを要求するエラーを通知します。自動再始動・自動増速はしません。停止後の記録保存は通常の終了処理に従います。模擬停動試験で400ms付近の検出と全軸停止を確認。


## v0.8.4 低速区間の短縮
最低速度初期8％、設定範囲1～100％、同期補正の最低値、停動検出、目標到達優先は維持します。台形/S字の時間曲線と時間指定の基準計算も維持。

応答推定は指令の変化が2度/秒以下の観測区間で行います。前後の指令と実測速度の差e1/e2が15度/秒超、5<e2<e1の場合、一次遅れの目安−dt/log(e2/e1)＋80msを計算。観測した最大値を200～500msの範囲で保持し、350ms以下と確認できた場合だけ余裕を縮めます。成立しない、推定が遅い場合は500msの従来値へ戻します。実機同定の保証ではなく、観測条件に基づく保守的な見積もりです。

短縮時の予測距離は(v＋f)D/2＋(v−f)τ＋v×制御周期余裕＋max(2度,f×0.25秒)。vは実速度と直前指令の大きい方、fは左右比率を反映した最低速度。0まで止めるための余裕を8％まで下げるための余裕と分け、最低速度分の余裕の重複を削ります。残り距離の上限もfへ向かう式へ変更。減速中の応答遅れが大きい場合は従来の上限へ戻します。短い動作や応答推定ができない場合は短縮しません。

旧v0.8.3の2関数を変更しない比較用資料として保持。台形/S字・20/50％・614/2046度・80/150/300/500ms応答の32条件で旧版と比較し、低速区間と全体時間が増えず、終端指令84度/秒以下・模擬実速度105度/秒以下で完走することを確認。S字20％・2046度・80msモデルでは8％指令区間1600→860ms、全体11700→11260ms。実機での短縮量は未確認です。


## v0.8.5 残り距離に沿った減速
角度・回転数・距離の有限動作で、減速開始後の経過時間だけによる速度低下を廃止。EBL-RTの考え方を参考に、毎回の残距離から最低速度へ向かう速度を再計算します。EV3RT本体の制御・同期APIを再現するものではありません。時間指定と加速のQ1000曲線は維持。

高速側へ正規化した残量と速度で計算。最低速度f、減速基準速度vは減速開始時点で加速できた指令速度。応答τは200～500msの範囲、実速度と直前指令の大きい方を観測速度とします。終端余裕時間=max(0.25,τ log(max(1,(観測速度−f)/max(10.5,0.2f)))＋0.5秒)。余裕距離=f×余裕時間＋2度。実速度が落ちるにつれて余裕距離を見直し、固定した最高速度分の低速走行を残しません。

a=min(525,max(10.5,(v−f)/設定減速秒))、S字はaを1.5で除算。減速幅=(v²−f²)/(2a)＋(v−f)×(τ＋周期)。余裕距離を引いた残量の比の平方根を0～1へ制限し、台形はその値、S字はsmoothstepでf～vへ変換。残距離・遅れによる運動学上限も併用し、減速中の上限は再上昇させません。最低8％、左右比率、目標到達優先、停動検出は維持。

旧v0.8.4比較32条件では8％指令の区間660～1160ms。50％・2046度・S字・80ms応答モデルは2480→660ms、全体7260→6480ms。20％・同距離・同応答では860→700ms、全体11260→11460ms。低速区間が短くても全体時間が延びる条件があります。遅い応答の一部は低速区間が最大160ms増えます。全条件で短縮するとの主張はしません。

既存96応答条件・24低速停止モデル・停動検出を再検証。終端指令84度/秒以下、模擬実速度105度/秒以下、目標到達、同期有効時の指令変化幅を確認。実機は未確認。既存8％設定のまま、20/50％・100cm・S字0.5/0.5秒・採取200msで比較してください。


## v0.8.6 時間の定義を統一（現行）
加速時間Uは最低fから指定最高Vへの名目速度指令の変化時間。減速時間DはVからfへの変化時間。加速f+(V−f)shape(t/U)、減速f+(V−f)shape(1−t/D)。shapeはQ1000台形またはsmoothstep。0秒は即時変更。約20msの制御周期と整数％の丸めがあるため、実時間には周期分の差が出ます。実速度の追従時間の保証ではありません。

残り距離は減速開始位置だけに使います。現在指令c、最低f、予定Dの平均速度による距離に、実測速度と指令の大きい方から推定した応答遅れ分と終端余裕を加えます。応答は開始位置へ反映し、Dは伸ばしません。加速途中に減速開始する場合は到達した指令速度をピークとして、Dを(c−f)/(V−f)倍へ縮めます。目標到達・明示停止は時間完了より優先。

同期補正は最大15％・最低値を維持。525度/秒²の制限を同期補正成分へ分離し、名目加減速カーブの変化量を前回指令へ加えてから補正成分の変化を制限します。名目0.1秒の変化を固定の変化制限で引き延ばしません。時間指定にも最低値を適用。T<U+Dの場合、r=T/(U+D)、ピーク=f+(V−f)r、U'=Ur、D'=T−U'。最低8％・V40％・T0.5秒・U/D各1秒ならピーク16％、各0.25秒です。

48条件（台形/S字、20/50％、0.1/0.5/1秒、同期有効/無効、距離/時間指定）で、最低→最高と最高→最低の指令到達時刻、中間曲線、減速途中で最低値へ先に丸まらないことを確認。短時間・0秒8条件、192応答条件（0.1/0.5秒、80～500ms非対称遅れ）、24低速モデル、停動停止も検証。旧版との低速区間時間の短縮比較は、時間定義が変わるため正解基準から外します。実機は未確認です。


## v0.8.7 距離比率を別ブロックとして追加
既存の秒指定を保ち、lab_ramp_distanceをモーター・動きの秒指定直後へ追加。台形/S字、加速・減速各0～100％、合計100％以下。先に全入力を検証し、有効な場合だけ共通設定を更新します。後から実行した秒指定／距離比率指定が有効。既存作品は秒指定のまま動作します。

距離比率は軸回転量から計算。各非ゼロ軸の符号をそろえた進み量をその軸の目標量で割り、0～1へ制限した平均xを使います。加速率a、減速率dを0～1とし、係数=min(1,x/a,(1−x)/d)。0の区間は式から除外。S字は係数へsmoothstepを適用。名目指令=f+(V−f)係数。同期補正・最低値・停止優先を維持し、距離モードの低速停動も検出します。左右比率を保つため共通最低値は遅い軸が最低速度になる値とし、指定最高速度を超えません。

100cm・10/10％なら指令区間0～10cm／10～90cm／90～100cm。床面距離はタイヤ径・滑り等でずれます。旋回も総軸回転量の割合です。時間動作へ距離比率を使う場合は命令前に明示エラーとし、秒指定への変更を案内します。時間に暗黙換算しません。

96条件の正逆・左右比・区間境界試験、12条件の非対称応答、範囲外・合計超過の原子的拒否、方式切り替え、時間動作拒否、保存読込とコード生成を確認。21個目のサンプルRatioRampを追加。実機未確認です。
