01 はじめに

ブロックで考え、SPIKE PRIME本体で確かめる。Chromebookを切り離して試せる、標準Hub OS向けのWebアプリです。

この版の対象

v0.2.0は、LEGO SPIKE App 3に対応する標準Hub OS用の試作版です。SPIKE-RTへの書き換えは不要です。SPIKE-RT対応は将来の発展目標として別に進めます。

実機動作は未検証です。自動試験とブラウザ確認は実施していますが、接続・停止・切断後実行・再起動は実機で確認してください。

学習の流れ

つくる → 作品を保存 → 本体に転送 → 切断して実行 → 数値や組み合わせを変えて再挑戦。

最初は「表示・ライト」「音だけ」から始めます。モーターを初めて動かすときは、車輪を浮かせて確認します。

マニュアルの説明はv0.2.0の画面・コード生成に対応します。LEGO公式アプリの教材・ファイル形式・全機能との互換性を示すものではありません。

02 画面と基本操作

EV3 Block Labと同じ配置を基本にしています。接続パネルを閉じると、ブロック編集に画面全体を使えます。

場所・操作使い方
プログラム名上部で名前を入力します。日本語の名前を使えます。保存ファイル名に使用します。
＋ 新しいプログラム新しい作品を始めます。残す作品は先に「保存」を押してください。
↓ 保存 / 開く編集可能な作品ファイルを保存・復元します。本体への転送とは別の操作です。
マイブロックを作る名前と引数を入力し、命令をまとめる定義ブロックを作ります。
その他マイブロック集の書き出し・読み込み、生成Pythonの表示を行います。
サンプル10種類のお手本へ置き換えます。元の作品を残す場合は先に保存します。
元に戻す / やり直す直前の編集を戻したり、戻した編集をやり直したりします。
全体を見る配置したブロックが見えるよう、編集領域の表示を調整します。
接続・転送右パネルを開閉します。接続、保存番号、転送、実行、停止、センサー表示があります。
通信ログ画面下で開閉します。問題が起きた場合は作品と一緒にログを保存します。

ブロックを置く

左側のグループを選び、使いたいブロックを編集領域へ出します。「スタート」の下に順につなぎます。数値をクリックして変更し、選択欄でポートや動作を選びます。

数値の丸い入力には、数値・変数・センサー・演算を差し込めます。条件の入力には比較や判定を入れます。空の入力は確認結果に案内されます。

未接続の試し置きブロックや、呼び出していないマイブロックは作品に保存されますが、本体への転送対象からは除外されます。

03 接続・転送・切り離し実行

ChromeでHTTPSのアプリを開きます。学校の管理端末では、Bluetooth機器への接続が許可されているか確認してください。

  1. ほかのSPIKEアプリや、本体に接続している別のタブを閉じます。
  2. SPIKE PRIMEの電源を入れ、Bluetoothボタンを押します。
  3. 右上の「接続・転送」→「接続する」で対象の本体を選びます。接続後の本体名・Hub OS版を確認します。
  4. 「本体の保存番号」を0〜19から選びます。同じ番号のプログラムは上書きされます。残したいプログラムの番号は使わないでください。
  5. 「SPIKEに転送」を押します。上書きの確認後に、停止指示と転送を行います。転送だけでは新しいプログラムは起動しません。
  6. 転送応答の確認表示が出たら「切断」を押し、ケーブルも外します。
  7. 本体で保存番号を選び、中央ボタンで実行します。通常の電源オフ・再起動後にも実行できるか確認します。
ボタン動作
SPIKEに転送本体へ保存します。実行は別操作です。
転送して実行転送応答を確認した後、すぐ実行指示を送ります。モーターが動く準備をしてから使用します。
転送したプログラムを実行接続中に、直前に転送したプログラムを起動します。編集や保存番号の変更後は再転送します。
実行を停止接続中の本体へ停止指示を送ります。切断後は本体で停止してください。

転送成功はCRC付き転送要求に対する本体の応答を確認した状態です。EV3版の全バイト読み戻し照合とは異なります。途中で失敗した場合、以前のプログラムが残る保証はありません。

04 モーターと走行

対象はSPIKE PRIMEのL/Mアンギュラーモーターです。速さは−100〜100％。このアプリでは100％を1050度/秒に換算します。負の値は逆回転です。

命令意味・設定
モーターを指定量回す接続ポート、速さ、度・回転・秒を指定します。1回転は360度。動作完了を待って次へ進みます。速さ0は使えません。
回し続ける回転を始め、次の命令へ進みます。後ろに待機や条件待ちを置き、停止命令と組み合わせます。
モーターを停止選択ポートまたはすべてを停止します。ブレーキ、惰性、保持を選びます。
走行の左・右モーター走行用の異なる2ポートを選びます。走行命令より先に実行してください。サンプルは左B・右Cです。
タイヤ直径距離を回転角度に換算するための設定です。実際のタイヤ直径をmmで入力します。初期値56mm。
指定量進む速さ、cm・秒・モーター角度、曲がり方を指定します。負の速さで後退します。
曲がり方−100〜100。0は直進、±100はその場で旋回する指定です。実際の左右方向と取り付けを確認します。
左右別速度で走り続ける左右の速さを別々に指定し、すぐ次へ進みます。走行ポート設定が必要です。

例：距離で停止

走行の左B・右Cを設定 → 左右を20％で走り続ける → 距離センサーDが15cm未満になるまで待つ → すべてのモーターを停止。

「回し続ける」だけでプログラム全体が終わると、終了処理で停止します。待機や繰り返しをつなぎ、動かし続ける時間を作ります。

本体全体のプログラムが終了すると全モーターを停止します。保持も終了処理では解除される場合があります。負荷、タイヤ、組み立て、床面によって距離・停止精度は変わります。

05 表示・ライト・音

画面表示と音はSPIKE本体で実行します。Chromebookを切り離しても使える機能を優先しています。

命令使い方
絵を表示にこにこ、ハート、やじるしを5×5ライトへ表示します。「けす」ですべて消灯します。
本体に文字を表示文字列、数値、変数などを表示します。英数字・記号に対応。表示完了を待って次へ進みます。
1ドットの明るさ横0〜4、縦0〜4、明るさ0〜100％を指定します。左上が横0・縦0です。
本体ランプ中央ボタン周辺のランプの色を選びます。表示ライトとは別です。
音を鳴らす高さHz、時間（秒）、音量％を指定します。初期値440Hz・0.3秒・30％です。音の終了を待って次へ進みます。

表示を確かめる

表示した直後にプログラムが終了すると、本体の通常表示へ戻る場合があります。表示ブロックの後に「1秒待つ」などを置いて確認します。

「表示・ライト」サンプルは、にこにこ → 1秒待つ → ハート → 1秒待つ、の順です。

本体で表示できる文字

日本語の作品名や変数名は使えますが、本体の文字表示は英数字・記号です。日本語文字を表示へ渡すと実行時にエラーになります。文字は120文字までを使用します。

LEGO公式アプリのPC側画像・録音・拡張効果音・教材素材は、この版には含めていません。

音ブロックの範囲は44〜10000Hz、時間0〜60秒、音量0〜100％です。はじめは小さな音量で確かめてください。

06 センサーと計測

センサーの読み取りと条件判断は本体で行います。読み直すときは、繰り返しの中にセンサーの値や条件を入れます。

値・条件単位・意味
距離cm。測定できない場合、数値ブロックは9999を返し、「近い」と誤判定しないようにします。
距離が測れている対象を測定できているかの条件です。距離を使った計算の前に組み合わせて確認します。
色 / 色番号指定色との一致条件、またはHub OSの色番号を返します。色番号をEV3の番号と同じと考えないでください。
反射光カラーセンサーの反射光。0〜100％です。明暗の境界は機体で測って決めます。
フォース押下 / 力押されているかを判定、または力をNで取得します。
本体左右ボタン左または右が現在押されているかを取得します。押した瞬間のイベントとは別です。
本体の向き・傾き向き、前後、左右の角度を度で取得します。「本体の向きを0にする」で向きをリセットします。
モーター角度選択ポートの相対回転角度を度で取得します。リセット命令で0にできます。
タイマー開始または最後のリセットからの秒数。プログラム全体で共有します。
接続パネルの値表示「値を読む・更新」で本体通知を表示します。モーター、距離、色、フォースの直近の値です。

ポートをそろえる

A〜Fはモーター・センサー共通です。同じプログラムで同じポートへ異なる機器の種類を指定すると、転送用コードの生成時に案内します。

計測表示の更新を止めても、本体で実行中のプログラム内のセンサー読み取りは続きます。切断するとブラウザ側の計測表示は消えます。

未接続や機器の種類違いでは、実行時にエラーになる場合があります。9999cmは実測値ではなく未検出の代替値です。モニターでは未検出を「測定できません」と表示します。

07 制御・演算・変数・リスト

順序、繰り返し、条件を組み合わせて考えます。センサー・演算・変数を数値や条件の入力に差し込めます。

グループ使い方
秒待つ / 条件まで待つ指定時間、または条件成立まで待ちます。条件が変わらなければ待ち続けます。
回数繰り返し / ずっと内側の命令を回数分、または終了まで繰り返します。「ずっと」の後ろへは通常進みません。
もし / でなければ条件によって実行する内側の命令を選びます。編集ボタンで条件の枝を追加できます。
条件付き繰り返し条件が続く間、または条件が成立するまで繰り返します。比較や論理を条件へ入れます。
すべて止めて終了プログラム全体を終了する命令です。本体上のモーターを止める終了処理へ進みます。
演算四則演算、比較、論理、絶対値などの関数、三角関数、丸め、余り、乱数、範囲制限があります。
変数「変数を作成」から名前を付けます。値にする、増やす、値を取り出すブロックを使います。
文字列文字、連結、長さ、出力を使えます。「出力」は通信ログ向けで、本体ライト表示とは別です。
リスト作成、長さ、空判定、項目取得・変更、検索を使います。初めにリストを変数へ設定してください。

例：回数を表示する

変数「回数」を0にする → 3回繰り返す［回数を1増やす → 本体に回数を表示 → 0.5秒待つ］。

変数は最初に値を設定してから読みます。演算結果やセンサーの値をモーターへ渡すときも、有効な範囲へ収まるか確かめます。

0で割る、範囲外の値、存在しないリスト項目などは実行時エラーの原因です。待機を含まない繰り返しにも内部で短い待機を入れ、ほかの処理が動く機会を作っています。

08 マイブロックとイベント

命令をまとめて再利用したり、走行と計測を並行して動かしたりできます。発展的な機能は、小さなサンプルで確かめてから組み合わせます。

引数付きマイブロック

上部の「マイブロックを作る」で名前を入力します。必要なら「距離, 速さ」のように引数をカンマで区切ります。引数は重複しない名前で8個までです。

できた定義ブロックの中へ命令を入れます。「マイブロック」グループから呼び出し、入力欄へ数値を入れます。引数の値は、対応する名前の変数ブロックで参照します。

例：前に進む［距離］を定義し、その中に距離を使う走行命令を入れます。呼び出しの距離を変えると、同じ定義を別の長さで使えます。

名前・引数の変更は定義ブロックの編集ボタンで行います。「その他」からマイブロック集を書き出し、別の作品へ読み込めます。同名の定義がある場合は読み込みを止めます。

複数スタートと条件イベント

スタートを複数置くと、本体で別々の処理として進みます。すべてのスタートが終わると終了処理へ進みます。一つの短い処理が終わっただけで全モーターを止める構成にはしていません。

条件イベントは、条件が偽から真へ変わったときに実行します。起動時から真の場合も1回実行します。押し続けている間に毎回実行するイベントではありません。

メッセージ

「メッセージを送る」と、同じ名前の受信イベントを動かせます。受信処理中に複数の通知が来た場合は、次の1回へまとめます。送信完了待ちは未実装です。

イベントは監視を続けるため、スタートの命令が終わってもプログラムが継続します。終了命令、ブラウザの停止、本体の停止操作で終了します。

並行処理で同じモーターや変数を同時に変更すると、結果が分かりにくくなります。最初は処理ごとの役割を分けてください。再帰呼び出しや複雑な同時更新は、この版では推奨しません。

09 サンプル10種類

サンプルを選ぶと現在の作品を置き換えます。残したい作品は先に保存してください。指定ポートを実際の接続へ合わせて使います。

サンプル接続・確認する動作
表示・ライト追加機器なし。にこにことハートを順に表示します。最初の転送確認に使います。
音だけ追加機器なし。本体から短い音を鳴らします。
モーターAAにモーター。速さ20％で90度ずつ正逆に回します。
前進・後退左B・右C。タイヤ直径56mmを実物に合わせ、10cmずつ前後へ動かします。
距離で停止左B・右C、距離D。走り続け、15cmより近い対象で停止します。
赤で音カラーD。赤を検出するまで待ってから音を鳴らします。
変数と分岐追加機器なし。変数を増やし、本体へ1、2、3を表示します。
引数付きマイブロック左B・右C。「前に進む」の距離引数を使って走行します。
走行と表示を並行左B・右C。走行とライトの切り替えを別スタートで進めます。
メッセージで合図追加機器なし。1秒待って合図を送り、受信側で音を鳴らします。

試行錯誤のしかた

はじめは一つの数値だけ変えます。予想 → 実行 → 結果を確認 → 直す、の順に進めます。うまくいった作品もファイルで残します。

走行を試す前に、モーター単体で回転方向と停止を確認します。次に短距離、最後にセンサー条件を加えると、違いを見つけやすくなります。

サンプルが動作したことは、すべての機体や組み合わせでの正確さを保証するものではありません。再起動後の単独実行も確認して記録してください。

10 困ったとき・先生向け確認

症状確認すること
接続ボタンが使えないChrome、HTTPS、Bluetooth対応、学校の管理設定を確認します。ローカル確認はlocalhostで開きます。
本体が候補に出ない本体電源・Bluetoothボタン、ほかのアプリやタブの接続を確認します。
転送が失敗する本体をつなぎ直し、保存番号を確認して再転送します。成功表示がない場合は未完了として扱います。
転送後に動かない転送だけでは実行しません。本体で保存番号を選ぶか、接続中に実行ボタンを使います。
前進方向が違う左右ポート、組み立て、速さの正負、実機での回転方向を確認します。
条件待ちが終わらない対象ポートと機器の種類、実測値、比較条件、距離の有効判定を確認します。
文字表示で止まる本体表示へ日本語を渡していないか確認します。英数字・記号へ変えます。
自動保存が消えた自動保存は同じブラウザの1作品分です。保存した作品ファイルを「開く」で復元します。

実機確認の順序

1. ライトと音 → 2. 本体保存・切断後実行・通常再起動 → 3. モーターと停止 → 4. 走行 → 5. センサー → 6. マイブロック・並行処理。

テスト日、端末とChromeOS版、本体Hub OS版、アプリ版、接続ポート、期待と実際の動作を記録します。問題の作品と通信ログを保存して共有します。
